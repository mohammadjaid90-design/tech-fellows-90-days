DAY 11 - CSS DAILY PRACTICE

HOW TO OPEN IN VS CODE
1. Download and extract the ZIP file.
2. Open Visual Studio Code.
3. Click File > Open Folder.
4. Select the extracted "day-11-vscode-project" folder.
5. Open index.html.
6. Right-click inside index.html and choose "Open with Live Server".
   If Live Server is not installed, install the Live Server extension.
   You can also open index.html directly in your browser.

FOLDER STRUCTURE
day-11-vscode-project/
    index.html
    css/
        style.css
