Good typography makes a website easier to read. A clear heading size helps people understand the page and find the information they need. Paragraphs should have enough space between lines so that reading does not feel difficult.

For a beginner website, it is better to use a small number of fonts and keep the text size consistent. A paragraph should not stretch across the full screen because very long lines are harder to follow. A maximum width of about 65 characters is a useful starting point.

Line height also makes a difference. A value such as 1.6 gives the text comfortable spacing. If line-height is set to 1.6px, the lines become too close together and the text is difficult to read.

This short paragraph demonstrates the incorrect line-height: 1.6px. The lines are squeezed together. Remove the bad-line-height class to restore normal spacing.
