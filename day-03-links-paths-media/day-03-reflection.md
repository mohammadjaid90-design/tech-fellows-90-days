
# Day 03 Reflection

## 1. Which path was easiest to get wrong, and why?
The image path was easiest to get wrong because the filename, extension, and folder name must match exactly.

## 2. How did you confirm a link points to the right destination?
I clicked each link in the browser and checked whether the correct page or section opened.

## 3. What is the difference between a page link and a fragment link?
A page link opens another HTML page. A fragment link uses an ID to jump to a particular section on a page.

## 4. What would you improve before showing this mini-site to another student?
I would improve the design, check accessibility, and test all links and images.

## 5. Bug, cause, and fix
Issue: The profile image did not load.
Cause: The image filename in the src attribute was incorrect.
Fix: I corrected the filename and refreshed the browser.
