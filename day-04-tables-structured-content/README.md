# Day 04 — HTML Tables and Structured Content

## What I Built
I created a weekly learning schedule using HTML tables.
The table includes a caption, three column headings,
five learning activities, and a summary row.

## Bug I Fixed
I temporarily removed a closing td tag to observe
how the browser handled the error. I then restored
the closing tag and checked the table again.

## What I Learned
I learned the difference between th and td.
I can explain how scope="col" identifies column
headings and scope="row" identifies row headings.

## Testing
I opened index.html in my browser, checked the table
structure, and tested the navigation links.
