# Day 06 - Accessibility Audit

## Project Name
Semantic HTML and Accessibility Review

## 1. Semantic HTML
**Finding:** The page uses header, nav, main, section, article and footer elements.

**Fix:** Semantic elements are used to organize the page content.

## 2. Heading Structure
**Finding:** The page has one main H1 heading and appropriate H2 and H3 headings.

**Fix:** Heading levels are arranged in a logical order.

## 3. Image Alt Text
**Finding:** The profile image has alternative text.

**Fix:** Make sure the image file exists and the alt text describes the image correctly.

## 4. Links
**Finding:** Navigation links and registration page links have descriptive text.

**Fix:** Test all links to make sure they open the correct pages.

## 5. Form Labels
**Finding:** Form inputs have labels connected using for and id attributes.

**Fix:** Keep every input ID unique and make required fields clear.

## 6. Keyboard Accessibility
**Finding:** Form controls use native HTML elements.

**Fix:** Test the page using Tab, Shift + Tab, Enter and Space keys.

## 7. Responsive Design
**Finding:** The HTML page includes a viewport meta tag.

**Fix:** Test the page at a narrow browser width.

## 8. Final Conclusion
