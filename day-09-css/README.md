# My Personal Website

This is my personal website project.

- about.html - About page
- style.css - CSS styling

- CSS selectors
- Margin and padding

- Consistent design

## How to Run
1. Download the project files.
2. Open the project folder in VS Code.
3. Open index.html in a web browser.
