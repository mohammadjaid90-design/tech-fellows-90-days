# Jaid - Student Portfolio

This is my Month 1 Tech Fellows project.

## Technologies
- HTML
- CSS
- JavaScript

## Sections
- Home
- About Me
- Skills
- Learning Goals
- Projects
- Contact

## Features
- Profile and project images
- Responsive design for mobile and computer
- Dark mode button
- Contact form validation

Note: The contact form is only for the website design. It does not send messages because there is no backend.

## How to Run
1. Open this folder in Visual Studio Code.
2. Open `index.html` in your browser.
3. Try the Dark Mode button and contact form.
